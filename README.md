# Shareit
Приложение для сдачи в аренду вещей (инструментами, книгами, гаджетами).

----------------
### Приложение состоит из двух сервисов:

- ***Gateway***

  Часть приложения, с которой непосредственно работают пользователи. В нём будет выполняться вся валидация запросов — некорректные будут исключаться.
  
- ***Основной***
  Основная логика приложения и обращения в БД
  * Работа с пользователями
  * Работа с вещами
  * Работа с запросами на аренду
  * Работа с комментариями
